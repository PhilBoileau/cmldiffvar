# Bound Vectors on Unit Interval Away from Zero and One

Bound Vectors on Unit Interval Away from Zero and One

## Usage

``` r
bound_away_from_0_and_1_fun(unit_interval_vec)
```

## Arguments

- unit_interval_vec:

  A numeric interval with values between zero and one.

## Value

A `numeric` vector with values bounded away from zero and one by some
small value.
